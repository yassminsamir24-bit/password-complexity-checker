\# Password Complexity Checker



This is a simple Python project that checks whether a password is valid based on common password complexity rules.



\## Features



\- Checks if the password contains uppercase letters

\- Checks if the password contains lowercase letters

\- Checks if the password contains digits

\- Checks if the password contains special characters

\- Checks if the password length is at least 10 characters



\## How It Works



The user enters a password, and the program checks each character to see if it meets the required conditions.



If the password contains all required character types and has a valid length, the program prints:
